# Release workflow — human controlled

Agents may prepare release notes, checklists, and deployment instructions. They must not execute production deployment.

1. Confirm release scope and target commit.
2. Verify CI, tests, security findings, and review status.
3. Check migration plan, backups, compatibility, and rollback.
4. Generate release notes and operational checklist.
5. Human verifies environment, credentials, approvals, and maintenance window.
6. Human initiates deployment using the organization's approved process.
7. Human verifies health checks, logs, metrics, and rollback criteria.
8. Record release outcome and follow-up issues.
