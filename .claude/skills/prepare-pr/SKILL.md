# Prepare pull request

Confirm branch and diff. Summarize problem, solution, user-visible changes, migration/API impact, tests actually run, security review, rollout/rollback notes, and known limitations. Generate a PR title and body. Do not push, open, approve, merge, or deploy unless the user explicitly requests the specific action and the connected tool is available. Human approval is required before merge and deployment.
